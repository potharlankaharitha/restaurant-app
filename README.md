# 🍔 Tasty Bites - Restaurant App

Users can browse menu, add items to cart, place order.

## Features
- Menu with Veg Biryani, Chicken Biryani, Pizza, Dosa
- Add to Cart with Total calculation
- Place Order with Order ID generation
- Fast loading, Cart saved using LocalStorage

## Tech Used
HTML, CSS, JavaScript
